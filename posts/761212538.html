# 综合实战：部署 httpd、Docker、Harbor、MySQL

本文是 Playbook 的综合实战，将前面学到的模块、变量、条件、循环、模板等特性组合起来，完成四个真实场景的部署：编译安装 httpd、批量安装 Docker、部署 Docker Harbor 私有仓库、多版本批量部署 MySQL。这些案例体现了 Ansible 在生产部署中的实际价值。

# 一、批量编译安装部署 httpd-2.4

通过 Playbook 实现 httpd 的下载、编译、配置、服务化全流程，综合运用 unarchive、shell、group、user、lineinfile、template、service 等模块，并用变量管理版本号与路径。

# install_httpd.yml
---
- hosts: websrvs
  remote_user: root
  vars:
    download_dir: /usr/local/src
    install_dir: /apps/httpd
    httpd_version: httpd-2.4.46
    apr_version: apr-1.7.0
    apr_util_version: apr-util-1.6.1
    httpd_url: https://mirrors.tuna.tsinghua.edu.cn/apache/httpd
    apr_url: https://mirrors.tuna.tsinghua.edu.cn/apache/apr

  tasks:
  - name: install packages
    yum: name=gcc,make,pcre-devel,openssl-devel,expat-devel,bzip2 state=installed
  - name: download httpd file
    unarchive: src="<!--swig￼0-->/<!--swig￼1-->.tar.bz2" dest=<!--swig￼2--> owner=root remote_src=yes
  - name: download apr file
    unarchive: src="<!--swig￼3-->/<!--swig￼4-->.tar.bz2" dest=<!--swig￼5--> owner=root remote_src=yes
  - name: download apr_util file
    unarchive: src="<!--swig￼6-->/<!--swig￼7-->.tar.bz2" dest=<!--swig￼8--> owner=root remote_src=yes
  - name: prepare apr dir
    shell: chdir=<!--swig￼9--> mv <!--swig￼10--> <!--swig￼11-->/<!--swig￼12-->/srclib/apr
  - name: prepare apr_util dir
    shell: chdir=<!--swig￼13--> mv <!--swig￼14--> <!--swig￼15-->/<!--swig￼16-->/srclib/apr-util
  - name: build httpd
    shell: chdir=<!--swig￼17-->/<!--swig￼18--> ./configure --prefix=<!--swig￼19--> --enable-so --enable-ssl --enable-cgi --enable-rewrite --with-zlib --with-pcre --with-included-apr --enable-modules=most --enable-mpms-shared=all --with-mpm=prefork && make -j <!--swig￼20--> && make install
  - name: create group
    group: name=apache gid=80 system=yes
  - name: create user
    user: name=apache uid=80 group=apache shell=/sbin/nologin system=yes create_home=no home=<!--swig￼21-->/conf/httpd
  - name: set httpd user
    lineinfile: path=<!--swig￼22-->/conf/httpd.conf regexp='^User' line='User apache'
  - name: set httpd group
    lineinfile: path=<!--swig￼23-->/conf/httpd.conf regexp='^Group' line='Group apache'
  - name: set variable PATH
    shell: echo PATH=<!--swig￼24-->/bin:$PATH >> /etc/profile.d/httpd.sh
  - name: prepare service file
    template: src=./httpd.service.j2 dest=/usr/lib/systemd/system/httpd.service
  - name: start service
    service: name=httpd state=started enabled=yes

systemd 服务模板 httpd.service.j2（用模板渲染安装路径）：

[Unit]
Description=The Apache HTTP Server
After=network.target remote-fs.target nss-lookup.target
Documentation=man:httpd(8)
Documentation=man:apachectl(8)

[Service]
Type=forking
ExecStart=<!--swig￼25-->/bin/apachectl start
ExecReload=<!--swig￼26-->/bin/apachectl graceful
ExecStop=<!--swig￼27-->/bin/apachectl stop
KillSignal=SIGCONT
PrivateTmp=true
[Install]
WantedBy=multi-user.target
ansible-playbook install_httpd.yml

该案例亮点：用 remote_src=yes 直接在远程下载解压；用变量管理版本与路径，模板渲染服务文件，make -j {{ ansible_processor_vcpus }} 按 CPU 数并行编译。

# 二、利用 Playbook 安装 Docker

批量在 Ubuntu 主机上安装 Docker，结合 when 条件区分 Ubuntu 18.04 与 20.04，演示跨版本兼容的安装。

准备：

# /etc/ansible/hosts
[ubuntu]
10.0.0.100
10.0.0.200
# vars.yml
docker_version: 5:19.03.15~3-0~ubuntu-
ubuntu1804: bionic
ubuntu2004: focal
# files/daemon.json（配置镜像加速）
{
  "registry-mirrors": ["https://<你的镜像加速地址>"]
}
# install_docker.yml
---
# install docker
- hosts: ubuntu
  remote_user: root
  vars_files:
    - vars.yml

  tasks:
    - name: install packages
      apt: name=apt-transport-https,ca-certificates,curl,software-properties-common state=present
    - name: import key
      shell: curl -fsSL https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/ubuntu/gpg | sudo apt-key add -
    - name: import installation source on ubuntu1804
      shell: add-apt-repository "deb [arch=amd64] https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/ubuntu <!--swig￼29--> stable"
      when:
        - ansible_facts['distribution_major_version'] == "18"
    - name: import installation source on ubuntu2004
      shell: add-apt-repository "deb [arch=amd64] https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/ubuntu <!--swig￼30--> stable"
      when:
        - ansible_facts['distribution_major_version'] == "20"
    - name: install docker for ubuntu1804
      apt: name=docker-ce=<!--swig￼31--><!--swig￼32-->,docker-ce-cli=<!--swig￼33--><!--swig￼34-->
      when:
        - ansible_facts['distribution_major_version'] == "18"
    - name: install docker for ubuntu2004
      apt: name=docker-ce=<!--swig￼35--><!--swig￼36-->,docker-ce-cli=<!--swig￼37--><!--swig￼38-->
      when:
        - ansible_facts['distribution_major_version'] == "20"
    - name: mkdir /etc/docker
      file: path=/etc/docker state=directory
    - name: mirror acceleration
      copy: src=/data/ansible/files/daemon.json dest=/etc/docker/
    - name: load daemon
      shell: systemctl daemon-reload
    - name: start docker
      service: name=docker state=started enabled=yes
ansible-playbook install_docker.yml
# 验证
ansible ubuntu -a "docker version"

# 三、利用 Playbook 安装 Docker Harbor

在安装 Docker 的基础上，进一步部署 Harbor 私有镜像仓库。需要准备 Harbor 离线安装包、docker-compose、harbor 配置脚本与服务文件。

准备：

# vars.yml
docker_version: 5:19.03.15~3-0~ubuntu-
ubuntu1804: bionic
ubuntu2004: focal
docker_compose_version: 1.27.4
harbor_version: 1.7.6
# files/harbor.sh（设置 harbor.cfg 的主机名与管理员密码）
#!/bin/bash
IPADDR=`hostname -I | awk '{print $1}'`
HARBOR_ADMIN_PASSWORD=<密码>
sed -i.bak -e 's/^hostname =.*/hostname = '$IPADDR'/' -e 's/^harbor_admin_password =.*/harbor_admin_password = '$HARBOR_ADMIN_PASSWORD'/' /apps/harbor/harbor.cfg
# files/harbor.service
[Unit]
Description=Harbor
After=docker.service systemd-networkd.service systemd-resolved.service
Requires=docker.service

[Service]
Type=simple
Restart=on-failure
RestartSec=5
ExecStart=/usr/bin/docker-compose -f /apps/harbor/docker-compose.yml up
ExecStop=/usr/bin/docker-compose -f /apps/harbor/docker-compose.yml down

[Install]
WantedBy=multi-user.target

files 目录内容： daemon.json、docker-compose-Linux-x86_64-1.27.4、harbor-offline-installer-v1.7.6.tgz、harbor.service、harbor.sh

# 四、批量部署 MySQL 5.7 / 8.0

下面四个案例演示用不同方式批量部署 MySQL，是变量、register、when、循环、脚本的综合运用。

# 4.1 案例 1：用 register 注册变量部署 MySQL 5.7/8.0

mkdir -p /data/ansible/files
cd /data/ansible
# files/ 下准备 my.cnf、mysql-5.7.33-linux-glibc2.12-x86_64.tar.gz、mysql-8.0.23-linux-glibc2.12-x86_64.tar.xz
# files/my.cnf
[mysqld]
server-id=1
log-bin
datadir=/data/mysql
socket=/data/mysql/mysql.sock
log-error=/data/mysql/mysql.log
pid-file=/data/mysql/mysql.pid

[client]
socket=/data/mysql/mysql.sock
# install_mysql5.7or8.0.yml
---
- hosts: dbsrvs
  remote_user: root
  gather_facts: no
  vars:
    mysql_version: 5.7.33
    mysql_file: mysql-<!--swig￼51-->-linux-glibc2.12-x86_64.tar.gz
    mysql_root_password: <root密码>

  tasks:
    - name: install packages
      yum:
        name:
          - libaio
          - numactl-libs
          - MySQL-python
        state: latest
    - name: create mysql group
      group: name=mysql gid=306
    - name: create mysql user
      user: name=mysql uid=306 group=mysql shell=/sbin/nologin system=yes create_home=no home=/data/mysql
    - name: copy tar to remote host and file mode
      unarchive: src=/data/ansible/files/<!--swig￼52--> dest=/usr/local/ owner=root group=root
    - name: create linkfile /usr/local/mysql
      file: src=/usr/local/mysql-<!--swig￼53-->-linux-glibc2.12-x86_64 dest=/usr/local/mysql state=link
    - name: data dir
      shell: /usr/local/mysql/bin/mysqld --initialize --user=mysql --datadir=/data/mysql
      tags: data
    - name: config my.cnf
      copy: src=/data/ansible/files/my.cnf dest=/etc/my.cnf
    - name: service script
      shell: /bin/cp /usr/local/mysql/support-files/mysql.server /etc/init.d/mysqld
    - name: PATH variable
      copy: content='PATH=/usr/local/mysql/bin:$PATH' dest=/etc/profile.d/mysql.sh
    - name: enable service
      shell: chkconfig --add mysqld;/etc/init.d/mysqld start
      tags: service
    - name: get password
      shell: awk '/A temporary password/{print $NF}' /data/mysql/mysql.log
      register: password
    - name: change password
      shell: /usr/local/mysql/bin/mysqladmin -uroot -p'<!--swig￼54-->' password <!--swig￼55-->
ansible-playbook install_mysql5.7or8.0.yml
# 若首次无法修改密码，先重置数据目录再执行一次
ansible dbsrvs -m shell -a "service mysqld stop;rm -rf /data/mysql/*"
ansible-playbook install_mysql5.7or8.0.yml

亮点：用 register: password 捕获初始化生成的临时密码，再用它设置 root 密码，实现无人值守改密。

# 4.3 案例 3：部署 MySQL 5.7（get_url 下载 + 重试改密）

# mysql_install.yml
---
- hosts: dbsrvs
  vars:
    password: <root密码>
  tasks:
    - name: download mysql-package
      get_url:
        url: http://mirrors.163.com/mysql/Downloads/MySQL-5.7/mysql-5.7.31-linux-glibc2.12-x86_64.tar.gz
        dest: /usr/local/mysql-5.7.31-linux-glibc2.12-x86_64.tar.gz
        force: yes
    - name: tar mysql-package
      unarchive:
        src: /usr/local/mysql-5.7.31-linux-glibc2.12-x86_64.tar.gz
        dest: /usr/local
        owner: root
        group: root
        mode: 0755
        copy: no
    - name: create linkfile /usr/local/mysql
      file:
        src: /usr/local/mysql-5.7.31-linux-glibc2.12-x86_64
        dest: /usr/local/mysql
        state: link
    - name: create bin link
      shell: "ln -s /usr/local/mysql/bin/* /usr/bin/"
      ignore_errors: yes
    - name: copy my.cnf
      copy:
        src: files/my.cnf
        dest: /etc/my.cnf
    - name: install packages
      yum:
        name: libaio,perl-Data-Dumper,perl-Getopt-Long
        state: present
    - name: create mysql group
      group:
        name: mysql
        gid: 306
    - name: create mysql user
      user:
        name: mysql
        uid: 306
        group: mysql
        shell: /sbin/nologin
        system: yes
    - name: create work directory
      file:
        path: /data/mysql
        state: directory
        mode: 0755
        owner: mysql
        group: mysql
    - name: Initialization mysql
      shell: "mysqld --initialize --user=mysql --datadir=/data/mysql"
      ignore_errors: yes
    - name: service script
      shell: "/bin/cp /usr/local/mysql/support-files/mysql.server /etc/init.d/mysqld;chkconfig --add mysqld;chkconfig mysqld on"
    - name: start service
      service:
        name: mysqld
        state: started
        enabled: yes
    - name: set root password
      shell: "mysqladmin -uroot -p\"`awk '/A temporary password/ {print $NF}' /data/mysql/mysql.log`\" password <!--swig￼60-->"
      register: error
      ignore_errors: yes
    - name: retry set new password
      shell: "mysqladmin -uroot -p'<!--swig￼61-->' password <!--swig￼62-->"
      when: error.failed

亮点：get_url 直接下载；改密失败时用 register + when: error.failed 实现自动重试。

# 4.4 案例 4：用 Shell 脚本部署 MySQL（结合 when 区分系统版本）

# vars.yml
mysql_version: 5.7.33
# files/set_password.sh
#!/bin/bash
MYSQL_ROOT_PASSWORD=<root密码>
MYSQL_OLDPASSWORD=`awk '/A temporary password/{print $NF}' /data/mysql/mysql.log`
mysqladmin -uroot -p$MYSQL_OLDPASSWORD password $MYSQL_ROOT_PASSWORD &>/dev/null
# install_mysql5.7.yml
---
- hosts: dbsrvs
  remote_user: root
  gather_facts: yes
  vars_files:
    - vars.yml

  tasks:
    - name: install packages for centos7
      yum: name=libaio,perl-Data-Dumper
      when: ansible_facts['distribution_major_version'] == "7"
    - name: install packages for centos8
      yum: name=libaio,perl-Data-Dumper,ncurses-compat-libs
      when: ansible_facts['distribution_major_version'] == "8"
    - name: create mysql group
      group: name=mysql gid=306
    - name: create mysql user
      user: name=mysql uid=306 group=mysql shell=/sbin/nologin system=yes create_home=no home=/data/mysql
    - name: copy tar to remote host and file mode
      unarchive: src=/data/ansible/files/mysql-<!--swig￼63-->-linux-glibc2.12-x86_64.tar.gz dest=/usr/local/ owner=root group=root
    - name: create linkfile /usr/local/mysql
      file: src=/usr/local/mysql-<!--swig￼64-->-linux-glibc2.12-x86_64 dest=/usr/local/mysql state=link
    - name: PATH variable
      copy: content='PATH=/usr/local/mysql/bin:$PATH' dest=/etc/profile.d/mysql.sh
    - name: PATH variable entry
      shell: . /etc/profile.d/mysql.sh
    - name: config my.cnf
      copy: src=/data/ansible/files/my.cnf dest=/etc/my.cnf
    - name: data dir
      shell: chdir=/usr/local/mysql ./bin/mysqld --initialize --user=mysql --datadir=/data/mysql
    - name: service script
      shell: /bin/cp /usr/local/mysql/support-files/mysql.server /etc/init.d/mysqld
    - name: enable service
      shell: /etc/init.d/mysqld start;chkconfig --add mysqld;chkconfig mysqld on
      tags: service
    - name: set mysql user password
      script: /data/ansible/files/set_password.sh
      tags: script
ansible-playbook install_mysql5.7.yml

亮点：用 when 区分 CentOS 7/8 安装不同依赖包；用 script 模块调用外部脚本完成改密，并用 tags 划分阶段。

# 小结

本文通过四个综合实战案例，展示了 Ansible 在真实部署中的组合应用：

  • httpd：变量管理版本路径 + 模板渲染服务文件 + 按 CPU 并行编译；
  • Docker/Harbor：跨发行版条件安装 + 镜像加速 + 服务化；
  • MySQL：多版本、多方式部署，综合运用 register 捕获临时密码、when 重试、when 区分系统、script 改密。

这些案例涵盖了变量、条件、循环、模板、注册变量等核心特性，是编写生产级 Playbook 的范本。下一篇将介绍 Ansible 的复用利器——Roles 角色，以及 Ansible Tower 管理平台。
