# 1. 计算机组成原理

# 1.1 什么是计算机

  • 计算机一般被称为"电脑"，即通电的大脑
  • "电脑"二字蕴含了人类对计算机终极的期望
  • 希望它能像人脑一样为我们工作，从而取代人力，并将人力解放出来

# 1.2 为什么要有计算机

  • 为什么要造计算机？其实是为了执行人类的程序，从而将人力解放出来（因为人存在很多不可控因素）
  • 计算机在设计时，每一部分都是在模仿人的某个器官或功能去设计的

# 1.3 计算机五大组成部分

计算机由五大组件组成，完全可以把它们比喻成人类的各种器官：

  • 控制器
  • 运算器
  • 存储器
  • 输入设备 Input / I 设备
  • 输出设备 Output / O 设备

# 1.3.1 CPU

控制器：

  • 作用：计算机的指挥系统，负责控制计算机其他所有组件如何工作
  • 比如：走路、跑、跳、说话都是谁在控制呢？
  • 类比：控制器 → 人类大脑

运算器：

  • 作用：运算（数学运算、逻辑运算）
  • 比如：1+1=数学运算；上车看见好看姑娘，追还是不追=逻辑运算
  • 类比：运算器 → 人类大脑

小结：

  • 控制器和运算器压根就不是两个硬件，控制器 + 运算器其实就是 CPU（芯片），类比人类的大脑（前脑+后脑）

CPU 其他知识：

  • CPU 路数：服务器中有多少个 CPU；单路=1 个 CPU，双路=2 个 CPU
  • CPU 核数：决定服务器并行（同时）处理任务的能力
  • CPU 超线程：一项 CPU 技术，原本 CPU 的核心和线程数量是对等的，利用超线程技术可以让一个核心对应多个线程：
    • i7 9700K：8 核心 16 线程（超线程）
    • i7 9800X：8 核心 8 线程（原生）
  • 原生只能 8 个核心同时工作，而超线程能 16 个核心同时工作
  • 超线程 CPU 同一时间能开更多程序，有效利用资源，提高整体运行效率

# 1.3.2 内存/硬盘

存储器 / IO：

  • 作用：负责程序数据的存取，有了存储器，计算机才有记忆功能

分类：

  • 内存：基于电工作，通电就可以存储数据
    • 优势：存取数据快
    • 缺点：断电数据会丢失，仅能临时存储
  • 硬盘：磁性存储
    • 优势：断电数据不会丢失，可永久保存
    • 缺点：存取速度慢

类比：

  • 内存 → 大脑的记忆功能（快、短期记忆）
  • 硬盘 → 随身携带小本本（慢、长期记忆）

举例：女朋友的生日假设是 0921，怎么记忆最佳：

  1. 单纯记录到脑子里可能会忘记，所以将生日记录到小本本上
  2. 在女朋友每次询问之前，将小本本拿出来看一眼，记到脑子中
  3. 在女朋友问的时候，直接从脑子记忆中提取她的生日日期即可

程序快存快取的三步流程：

  1. 将应用程序存储至硬盘中，不用就放在那，不占多少空间
  2. 一旦需要使用该程序，首先将程序存储在硬盘的数据加载到内存中
  3. 最后 CPU 读取内存中的指令，进行分析和处理，保证程序执行速度

# 1.3.3 输入设备

输入设备 Input：

  • 作用：往计算机里面输入内容（键盘、鼠标）
  • 比如：眼睛看、耳听等
  • 类比：输入设备 → 人类的（眼、耳）

# 1.3.4 输出设备

输出设备 Output：

  • 作用：计算机向外输出数据的工具（显示器、打印机）
  • 比如：人说话，人发布文章
  • 类比：输出设备 → 人类的（嘴、手）

# 1.3.5 五大组件总结

用"老师讲课、学生听课"来类比：老师是程序员，学生是计算机。

  1. 学生通过耳朵听、眼睛看，接收老师讲的知识 → 输入
  2. 学生通过神经，将接收的信息存入短期记忆 → 内存
  3. 大脑从短期记忆里取出知识/指令，分析知识/指令，然后学习知识/执行指令 → CPU（取指、分析、执行）
  4. 学生通过作业、给其他学生讲解，将学到的东西表达出来 → 输出
  5. 学生想要永久保存知识，进行长期记忆，需要将内容写到本子上 → 硬盘

# 1.4 计算机三大核心硬件

将五大组成部分进一步提炼出三大核心硬件：CPU、内存、磁盘。因为一个程序的运行与三大核心硬件存在特定的联系。

前提：人 --通过--> 语言 --控制--> 计算机

举例：通过语言编写一段程序，控制计算机做：1. 买烟；2. 吃饭；3. 回家。目的是控制人的身体去运转、替我们工作。

问题 1：程序没有详细描述如何工作，到底是哪个组件下发的控制指令？

  • 其实计算机的所有组件都受 CPU 控制
  • 程序直接控制大脑（CPU），由大脑（CPU）间接支配肉体（组件），实现程序支配肉体工作

问题 2：不想每次反复描述这件事，希望任务反复运行怎么办？

  • 计算机具备存储的是内存和硬盘
  • 如果直接存储在内存丢失了怎么办？所以程序需要存储在硬盘上
  • 编写好的程序或软件一定是存储在硬盘上的

问题 3：只有 CPU 和硬盘，能否将程序运行起来？

  • 可以运行，CPU 从硬盘中取出指令运行，但存在问题
  • CPU 速度远高于硬盘，如果每次都从硬盘读一条、CPU 处理一条，大量时间浪费在数据读取上
  • 需要内存的介入：
    1. 将步骤存储至磁盘（小本本）
    2. 将硬盘数据加载进内存（大脑的记忆）
    3. CPU 从内存中读取指令运行，效率非常高

# 1.5 操作系统基本概念

# 1.5.1 操作系统由来

需求：开发一个编辑工具，其核心业务是文本编辑，编辑内容就牵扯到要操作计算机硬件。

问题：

  1. 不管编写什么软件，最终目的是控制硬件
  2. 但计算机是死的，不可能自行运行，所有硬件运行都需要软件支配

解决：

  1. 先开发一个控制系统来控制计算机的硬件基本运行
  2. 再开发编辑工具的业务功能，但凡涉及操作硬件，则调用控制系统
  3. 最后由控制系统来控制计算机硬件进行运行

# 1.5.2 什么是操作系统

前面所说的控制系统有一个更好听的名称——操作系统（Operating System，OS）。

  1. 操作系统是应用软件与硬件之间的一个桥梁
  2. 同时是一个协调、管理、控制计算机硬件资源与软件资源的控制程序

结构层级：系统调用、命令、图标、窗口 → 操作系统 → 计算机硬件

# 1.5.3 为什么需要操作系统

  1. 控制计算机的基本运行
  2. 将硬件的复杂操作简单化，供上层应用程序使用
  3. 为用户与计算机硬件之间提供图形/命令行工具

# 2. Linux 系统基本介绍

# 2.1 什么是 Linux

Linux 和常见的 Windows 一样，都是操作系统，但 Linux 有两种含义：

  • 一种是 Linus 编写的开源操作系统的内核
  • 另一种是广义上的操作系统

Linux 与 Windows 的不同：

  • Windows：收费，不开源，主要用于日常办公、游戏、娱乐
  • Linux：免费，开源，主要用于服务器领域，性能稳定、安全、更新频次高

例如：淘宝、百度、腾讯等互联网公司，使用的服务器全都是 Linux 系统。

# 2.2 Linux 能从事哪些行业

  • 具备企业服务器基础运维能力、自动化运维，如：电商、游戏、金融、物流等
  • 具备企业数据库运维能力，掌管公司核心命脉系统，如：银行、金融、电商
  • 具备企业公有云运维能力，如：阿里云、腾讯云等
  • 具备企业集群架构维护能力，如：上百台甚至上千台规模的架构维护与实施
  • 具备企业代码发布能力，如：如何快速对数百台服务器进行项目迭代
  • 具备企业私有云平台构建及运维，如：构建企业私有云平台、容器平台
  • 能够解决运维过程中的各种问题，如：网站访问慢排查、网站加速、数据恢复、业务扩展等

# 2.4 Linux 系统发展历史

虽然历史不太重要，但需要了解 Linux 发展过程中的一些重要人物。

# 2.4.1 自由软件之父

  • 自由软件之父 Richard M. Stallman 于 1984 年发起了 GNU 组织

GNU 组织中的项目：

  • copyleft：代表无版权；copyright：代表有版权
  • opensource：开放源代码，软件谁都可以使用、谁都可以传播、谁都可以二次开发
  • free：免费
  • GPL：通用版权许可证协议，如果软件被打上 GPL，任何人都可以对该软件进行修改，但修改完后必须将源码发布出来，以便更好地传承

总结：

  • Linux 中的软件百分之八十都是 GPL 提供
  • 自由软件运动的口号是："团结就是力量"

# 2.4.2 Linux 系统之父

  • Linux 之父 Linus Torvalds（林纳斯·托瓦兹） 于 1991 年编写 Linux 内核

内核与操作系统的关系：

  • 操作系统的核心称为内核，但内核并不等于操作系统
  • 内核提供系统服务，如文件管理、虚拟内存、设备 I/O 等；还包含基本的程序、编译器、shell 等
  • 单独的 Linux 内核无法工作，需要有 GNU 项目的众多应用程序
  • Linux 官方叫法是 GNU/Linux（GNU 的软件 + Linux 内核），一般简称 Linux

# 2.4.3 Linux 系统发行版

我们现在说的 Linux 其实都是指发行版（distribution version）：使用 Linux 内核 + 各种 GNU 库文件、应用程序，构造而成的操作系统。

主流发行版：RHEL、CentOS、Ubuntu、SUSE

  • Redhat：企业级操作系统，将 Linux 内核编译、安装相应软件，进行专业测试后发行
  • CentOS：社区企业级操作系统，与 Redhat 完全开源
  • Ubuntu：社区维护，现在主要做手机系统和电脑桌面系统
  • Debian：社区发行版

# 2.4.4 为什么使用 CentOS

  • CentOS 是 Community Enterprise Operating System 的缩写，即"社区企业操作系统"
  • CentOS 兼具 Community（社区） 和 Enterprise（企业） 的特性
  • CentOS 稳定、长期支持（10 年），适合大规模使用

# 2.5 Linux 认证是否需要考

Linux 相关认证：RHCSA、RHCE、RHCA

  • 架构师 - RHCA：从数据中心到终端桌面的 Linux 系统设计、计划、部署及管理
  • RHCSS：高级安全认证，为满足企业环境下的安全要求，配置红帽企业版 Linux 和红帽目录服务
  • 工程师 - RHCE：安装和配置 Linux 服务器、网络设备、网络安全、实际问题的诊断和解决
  • RHCSA：安装和调试 Linux 系统、安全性，解决域和三域网络问题

常见问题：到底要不要考一个红帽证书？学完 Linux 云计算课程能不能考？

# 3. Linux 系统安装

# 3.1 安装配置 VM 虚拟机

VMware Workstation 是一款桌面计算机虚拟软件，让用户能够在单一主机上同时运行多个不同的操作系统。

# 3.2 安装 Linux 操作系统

安装 RHEL/CentOS 7 系统时需要注意：电脑的 CPU 需要支持 VT（Virtualization Technology 虚拟化技术）。

  • VT 指的是让单台计算机能够分割出多个独立资源区，并让每个资源区按照需要模拟出系统的一项技术
  • 本质是通过中间层实现计算机资源的管理和再分配，让系统资源的利用率最大化

注意：如果开启虚拟机后依然提示 CPU 不支持 VT 技术，请重启电脑并进入 BIOS 开启 CPU 的 VT 虚拟化功能。

安装步骤：

  1. 在虚拟机管理界面单击"开启此虚拟机"按钮，数秒后看到 RHEL 7 系统安装界面

选项含义

Test this media & install Red Hat Enterprise Linux 7校验光盘完整性后再安装
Troubleshooting启动救援模式
  1. 按回车键后开始加载安装镜像，所需时间约 30-60 秒，请耐心等待

# 4. Bash Shell 快速入门

# 4.1 什么是 Bash shell

Bash Shell 是一个命令解析器，可以通过 Bash Shell 命令让用户直接与内核进行交互：

  1. 用户通过 Bash 窗口输入 ls 命令
  2. ls 命令通过 Bash 窗口传递给操作系统内核程序
  3. 内核程序将命令翻译为计算机硬件能识别的语言，然后驱动硬件
  4. 硬件执行后将结果返回给内核，内核转换后返回给 Bash

如何打开 Bash Shell：

  • 使用远程连接工具连接 Linux 服务时，系统会自动打开一个默认的 shell
  • 可以在该界面执行命令，如获取系统当前时间、创建用户等

# 4.2 Bash Shell 能干什么

使用 Shell 实现对 Linux 系统的大部分管理，例如：

  1. 文件管理
  2. 权限管理
  3. 用户管理
  4. 磁盘管理
  5. 网络管理
  6. 软件管理
  7. 服务管理
  8. 等等

# 4.3 如何使用 Bash Shell

  • 单条命令 → 效率低 → 适合少量工作
  • Shell 脚本 → 效率高 → 适合重复性工作

例如：创建 100 个用户，单纯输入命令需要执行 100 次，而使用 Shell 脚本则可以轻松解决：

[root@web ~]# cat useradd.sh
#!/usr/bin/bash

# 创建100个用户

for i in {1..100}
do
useradd alice-$i
echo "alice-$i" is create ok..
done

# 4.4 Bash Shell 提示符

打开或登陆终端时会显示一长串提示符，提示符一般包含当前登陆的用户名、主机名、当前工作路径等：

[root@web ~]#
  • root：当前登陆 Shell 的用户名称
  • web：当前系统主机名称
  • ~：当前所在的工作目录
  • #：管理员提示符；$：普通用户提示符

# 4.5 Bash Shell 基础语法

bash shell 命令行为用户提供命令输入，然后将执行结果返回给用户：

命令       选项       参数
command    options    parameters

命令示例：

[root@web ~]# ls           # 查看目录
[root@web ~]# ls -a        # 查看所有（含隐藏文件）
[root@web ~]# ls -a /home/ # 查看指定目录
  • 命令：bash shell 命令的主体功能
  • 选项：用于调节命令的具体功能
    • - 引导短格式选项（单个字符），例如 -a
    • -- 引导长格式选项（多个字符），例如 --all
    • 多个短格式选项可以写在一起，只用一个 -，例如 -al
  • 参数：命令操作的对象，如文件、目录名等
  • 注意：命令必须开头，选项和参数位置可以发生变化

# 4.6 Bash Shell 基本特性

# 4.6.1 补全功能 Tab

  1. 命令补全：当忘记命令时，可以使用 Tab 进行补全
  2. 目录补全：当需要查找文件目录层级比较多时，可以使用 Tab 快速补全，减少出错
[root@web ~]# ifcon<按Tab键>
[root@web ~]# ifconfig

# 连续按两次Tab键，列出所有以if开头的命令
[root@web ~]# if<按两次Tab键>
if      ifconfig ifenslave ifrename
ifcfg   ifdown   ifnames   ifup

# 目录补全
[root@web ~]# ls /etc/sysconfig/network-scripts/

# 4.6.2 常用快捷键 Ctrl

快捷键可以大大提升工作效率：

  • Ctrl + a：光标跳转至正在输入的命令行的首部
  • Ctrl + e：光标跳转至正在输入的命令行的尾部
  • Ctrl + c：终止前台运行的程序
  • Ctrl + d：在 shell 中表示退出当前 shell
  • Ctrl + z：将任务暂停，挂至后台
  • Ctrl + l：清屏，和 clear 命令等效
  • Ctrl + k：删除从光标到行末的所有字符
  • Ctrl + u：删除从光标到行首的所有字符
  • Ctrl + r：搜索历史命令，利用关键字

# 4.6.3 历史记录 History

历史记录可用于追溯系统之前执行过什么命令、造成的故障、之前发生的情况。

1. 使用双 !! 执行上一条执行过的命令：

[root@web ~]# ls
file.txt
[root@web ~]# !!
ls
file.txt

2. 输入 !6，执行 history 命令历史中第 6 行命令：

[root@web ~]# !6
touch file.txt

3. 使用 !cat，调用 history 中最近一次执行过的 cat 命令：

[root@web ~]# cat /etc/sysconfig/network-scripts/ifcfg-eth0
[root@web ~]# !cat
cat /etc/sysconfig/network-scripts/ifcfg-eth0

# 4.6.4 命令别名 alias

命令别名将用户经常使用的复杂命令简单化，用 alias 别名名称='命令' 创建属于自己的命令别名；取消别名用 unalias 别名名称。

1. 定义临时别名，wk 为查看 eth0 网卡的别名：

[root@web ~]# alias wk='ifconfig'
[root@web ~]# wk

2. 如果定义命令本身，会执行什么？：

[root@web ~]# alias ifconfig='ifconfig eth0'
# 直接输入ifconfig会执行别名（只显示eth0）
# 使用完整路径可绕过别名
[root@web ~]# /sbin/ifconfig
# 使用反斜杠转义可绕过别名
[root@web ~]# \ifconfig

3. 取消别名：

[root@web ~]# unalias ifconfig

4. 永久生效，写入 /etc/bashrc：

[root@web ~]# echo "alias ifconfig='ifconfig eth0'" >> /etc/bashrc

# 4.6.5 帮助手册 help

1. 命令 --help 帮助：

[root@web ~]# ls --help

2. 命令 man 手册：

[root@web ~]# man ls

3. Linux 命令大全：可通过 Linux 命令大全、Linux 命令手册在线网站查询。
