# Linux 文件编辑

本篇聚焦 Linux 下最重要的文本编辑器 Vim，系统介绍 Vim 的三种模式（普通模式、编辑模式、末行模式）及视图模式，讲解各模式下的快捷键操作、配置环境变量、vimdiff 文件比对、异常退出处理，并通过两个完整练习示例巩固 Vim 实战能力。

# 1. Vim 基本概述

# 1.1 什么是 vim

vi 和 vim 是 Linux 下的文本编辑工具，可以理解为 Windows 的记事本，或 Notepad++。

# 1.2 为什么需要 vim

因为 Linux 一切皆为文件，而工作中最多的就是修改某个服务的配置（其实就是修改文件内容）。如果没有 vi/vim，很多工作都无法完成，所以 vim 是学习 Linux 最重要的命令之一。

# 1.3 vi 与 vim 的区别

vi 和 vim 都是文本编辑器，vim 是 vi 的增强版，比 vi 多了语法高亮显示，其他编辑功能几乎无差，使用 vi 还是 vim 取决个人习惯。

由于前期采用最小化安装操作系统，所以没有 vim 命令，可以使用以下命令安装：

yum install vim

# 1.4 如何使用 vim

在使用 vim 之前，需要先了解 vim 的三种模式：普通模式、编辑模式、末行模式。每种模式支持多种不同的快捷键，要想高效率操作文本，必须先搞清三种模式的操作区别及模式之间的切换方法。

VIM 三种模式介绍：

  1. 普通模式：主要控制光标移动，可对文本进行复制、粘贴、删除等工作。
    • 使用 vim filename 编辑文件时，一进入文件就是普通模式
    • 在此模式下可进行光标移动、复制、删除、粘贴操作
  2. 编辑模式：主要进行文本内容编辑和修改
    • 从普通模式进入编辑模式，只需按一个键：i、I、a、A、o、O
    • 进入编辑模式时，屏幕最下一行会出现 INSERT 标记
    • 从编辑模式回到普通模式只需按 Esc 键
  3. 末行模式：主要用于保存或退出文本
    • 在普通模式下输入 : 或 / 即可进入末行模式
    • 在此模式下可进行：显示行号、搜索、替换、保存、退出

小结：vim 编辑打开文件整体流程：

  1. 默认打开文件处于普通模式
  2. 从普通模式切换至编辑模式需要使用 a、i、o
  3. 编辑模式修改完毕后需要先使用 Esc 返回普通模式
  4. 在普通模式输入 : 或 / 进入末行模式，可实现文件的保存与退出

注意：在 vim 中，无法直接从编辑模式切换到末行模式，必须先返回普通模式。

# 2. Vim 模式使用

# 2.1 普通模式

普通模式主要用于光标移动、复制、粘贴、删除、替换。

#1. 光标移动

G      # 跳转至文件的末尾

gg     # 跳转至文件的首行

Ngg    # 跳转至第N行，如 5gg 跳转至第5行

$      # 跳转至光标所在行的行末

0      # 跳转至光标所在行的行首

#2. 翻页

Ctrl+f   # 向下翻一页（full）

Ctrl+b   # 向上翻一页（back）

#3. 复制粘贴

yy     # 复制当前光标所在整行内容

5yy    # 复制当前光标以及光标向下4行（共5行）

p(小写)  # 粘贴至当前光标下一行

P(大写)  # 粘贴至当前光标上一行

#4. 删除、剪切、替换

dd      # 删除当前光标所在整行内容

5dd     # 删除当前光标以及光标向下4行（共5行）

dG      # 删除从当前行到文件末尾的所有内容

D       # 删除从当前光标到行末的所有内容

x       # 删除当前光标所在字符

5x      # 删除当前光标及其后面4个字符（共5个）

dd & p  # 删除并粘贴，相当于剪切（number dd、dG 同理）

u       # 撤销上一步操作

#5. 替换

r       # 替换当前光标所在字符

R       # 进入替换模式，从当前光标开始替换，按Esc退出

# 2.2 编辑模式

编辑模式主要用于编辑文件，以下按键从普通模式进入编辑模式：

i   # 在当前光标前插入，进入编辑模式（最常用）

a   # 在当前光标后插入，进入编辑模式

o   # 在当前光标下一行插入新行，进入编辑模式

I   # 在当前行行首插入，进入编辑模式

A   # 在当前行行末插入，进入编辑模式

O   # 在当前光标上一行插入新行，进入编辑模式

# 2.3 末行模式

末行模式主要用于搜索、保存、退出文件。

#1. 保存与退出

:w       # 保存当前状态

:w!      # 强制保存当前状态

:q       # 退出当前文档（文档必须保存才能退出）

:q!      # 强制退出文档，不会修改当前内容

:wq      # 先保存，再退出

:wq!     # 强制保存并退出

:X       # 先保存，再退出

ZZ       # 保存退出（Shift+Z+Z）

:number  # 跳转至对应的行号

#2. 搜索

/string  # 搜索指定字符串（从前往后搜索）

n        # 继续向下查找下一个匹配项

N        # 继续向上查找上一个匹配项

#3. 替换

:1,5s#sbin#test#g   # 将第1-5行中的sbin替换为test

:%s#sbin#test#g     # 将整个文件中的sbin替换为test

:%s#sbin#test#gc    # 替换时逐个确认（g全局，c确认）

#4. 跳转（另存为）

:w /root/test.txt   # 将当前文件保存到/root/test.txt

#5. 在文件中插入内容

:sp /etc/hosts     # 横向分屏打开/etc/hosts

:5r /etc/hosts     # 在第5行后插入/etc/hosts的内容

# 2.4 视图模式

视图模式（从普通模式进入视图模式），主要用于批量操作。

Ctrl+v 进入可视块模式，选中需要注释的行：

  1. 插入：按 Shift+i 进入编辑模式，输入 #，结束按 Esc 键
  2. 删除：选中内容后，按 x 或 d 键删除
  3. 替换：选中需要替换的内容，按下 r 键，然后输入替换后的内容

Shift+v 进入可视行模式，选中整行内容：

  1. 复制：选中行内容后按 y 键即可复制
  2. 删除：选中行内容后按 d 键删除

# 3. Vim 扩展知识

# 3.1 vim 配置环境变量

1. 临时设置打开文件的"显示行号""忽略大小写"等环境：

:set nu          # 显示行号

:set ic         # 忽略大小写

:set ai          # 自动缩进

:set list        # 显示特殊字符（如制表符）

:set no[nu|ic|ai...]  # 取消对应的设置

2. 永久生效：需要将内容写入配置文件中：

  • ~/.vimrc：个人环境变量，针对当前用户（优先级高）
  • /etc/vimrc：全局环境变量，针对系统中所有用户

如果个人 vim 环境没有配置，则使用全局 vim 环境变量配置；如果个人和全局产生冲突，优先使用个人 vim 环境变量。

# vim ~/.vimrc
set nu
set ic

# 3.2 vimdiff 文件比对

相同文件之间差异对比，通常用于对比修改前后差异。

# diff     # 普通的文件比对命令

# vimdiff  # 使用vim的方式打开文件进行比对，更直观

# 3.3 vim 异常退出处理

当使用 vim 打开一个新文件时，如果修改了文件内容，此时强制退出终端，会造成异常现象（产生 .swp 临时文件）。

解决方法：删除该文件的 .swp 文件即可。

# 假设打开filename文件后异常关闭，需要删除该文件的.swp文件即可解决
# rm -f .filename.swp

# 4. Vim 练习示例

# 4.1 vim 练习示例 1

需求：

  1. 将 /etc/passwd 复制到 /root/ 目录下，并重命名为 test.txt
  2. 用 vim 打开 test.txt 并显示行号
  3. 分别向下、向右、向左、向右移动 5 个字符，分别向下、向上翻两页
  4. 把光标移动到行末，再移动到行首，移动到 test.txt 文件的最后一行，移动到文件的首行
  5. 搜索文件中出现的 root 并数一下一共出现多少个，不区分大小写搜索
  6. 把从第一行到第三行出现的 root 替换成 --dd--，然后还原上一步操作
  7. 把整个文件中所有的 root 替换成 --dd--
  8. 把光标移动到 20 行，删除本行，还原上一步操作
  9. 删除第 19 行，还原上一步操作
  10. 删除从 5 行到 10 行的所有内容，还原上一步操作
  11. 复制 2 行并粘贴到 11 行下面，还原上一步操作（按两次 u）
  12. 复制从 11 行到 15 行的内容并粘贴到 8 行上面，还原上一步操作（按两次 u）
  13. 把 13 行到 18 行的内容移动文件的尾部，还原上一步操作（按两次 u）
  14. 光标移动到首行，把 /sbin/nologin 改成 /bin/bash
  15. 在第一行下面插入新的一行，并输入 # Hello1
  16. 保存文档并退出

# 4.2 vim 练习示例 2

需求：

  1. 使用 vim 打开 proxy.conf 文件
  2. 修改 Listen 为 listen 小写，并将 8080 修改为 80
  3. 修改 ServerName 为 server_name 小写
  4. 修改 vim.EXAMPLE.com 为 vim.example.com
  5. 在 server_name 行下插入一行 root /code;
  6. 复制 5-14 行的内容，然后将其粘贴到 14 行下面
  7. 删除与 proxy_set_header 相关的两行全部删除
  8. 如上操作完成后，在 13-20 行前面加上 # 号
  9. 删除 21-23 的行，然后保存当前文件

原始 proxy.conf 文件内容：

server {
    Listen 8080;
    Server_Name vim.EXAMPLE.com;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $http_host;
        proxy_set_header X-Forward-for;
        proxy_intercept_errors on;
        proxy_next_upstream error timeout;
        proxy_next_upstream_timeout 3s;
        proxy_next_upstream_tries 2;
        error_page 500 502 403 404 = /proxy_error.html;
    }
    location = /proxy_error.html {
        root /code/proxy;
    }
}
