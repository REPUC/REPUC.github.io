# Linux 文件查找

本篇介绍 Linux 下 find 命令的文件查找用法，涵盖查找语法、基于名称/大小/类型/时间/用户/权限的查找方式，以及查找后的动作处理与性能优化技巧。

# 1. find 查找概述

# 1.1 为什么需要查找

  • 很多时候我们可能会忘了文件所在的位置，此时就需要通过 find 来查找。
  • 有时候需要通过内容查找到对应的文件，此时也需要通过 find 来查找。

# 1.2 为什么是 find

因为 find 命令可以根据不同的条件来进行查找文件，比如：

  • 文件名称
  • 文件大小
  • 文件时间
  • 属主属组
  • 权限 等等

可以通过如上几种方式查找文件，从而实现精准定位。

# 1.3 find 命令语法

命令   路径      选项      表达式     动作
find   [path...] [options] [expression] [action]

# 2. find 查找示例

# 2.1 find 基于名称查找

#1. 创建测试文件
touch /etc/sysconfig/network-scripts/{ifcfg-eth1,IFCFG-ETH1}

#2. 查找 /etc 目录下文件名称为 ifcfg-eth1 的文件
[root@jaxxwang ~]# find /etc -name "ifcfg-eth1"

#3. -iname 忽略大小写查找
[root@jaxxwang ~]# find /etc -iname "ifcfg-eth1"

#4. 使用通配符查找
[root@jaxxwang ~]# find /etc/ -name "ifcfg-eth*"
[root@jaxxwang ~]# find /etc -iname "ifcfg-eth*"

# 2.2 find 基于大小查找

#1. 查找大于 5M 的文件
[root@jaxxwang ~]# find /etc -size +5M

#2. 查找等于 5M 的文件
[root@jaxxwang ~]# find /etc -size 5M

#3. 查找小于 5M 的文件
[root@jaxxwang ~]# find /etc -size -5M

# 2.3 find 基于类型查找

# f 普通文件
[root@jaxxwang ~]# find /dev -type f

# d 目录
[root@jaxxwang ~]# find /dev -type d

# l 链接文件
[root@jaxxwang ~]# find /dev -type l

# b 块设备文件
[root@jaxxwang ~]# find /dev -type b

# c 字符设备文件
[root@jaxxwang ~]# find /dev -type c

# s 套接字文件
[root@jaxxwang ~]# find /dev -type s

# p 管道文件
[root@jaxxwang ~]# find /dev -type p

# 2.4 find 基于时间查找

时间参数说明（按天/按分钟）：

参数含义
+77 天之前
-77 天之内
7正好 7 天
#1. 创建测试文件，设置不同时间
[root@jaxxwang ~]# for i in {0..10};do date -s 201904$i && touch file-$i;done

#2. 查找修改时间在 7 天之前的文件（按天）
[root@jaxxwang ~]# find ./ -iname "file-*" -mtime +7

#3. 查找修改时间在 7 天之内的文件（按天）
[root@jaxxwang ~]# find ./ -iname "file-*" -mtime -7

#4. 查找正好修改时间为 7 天前的文件（按天）
[root@jaxxwang ~]# find ./ -iname "file-*" -mtime 7

#5. 案例：查找 /var/log 下超过 7 天的 .log 文件，并删除
[root@jaxxwang ~]# find /var/log -type f -name "*.log" -mtime +7 -delete

# 查找 2 小时内修改过的文件（按分钟）
[root@node ~]# find ./ -type f -mmin -120
./file.txt

# 查找 5 分钟内修改过的文件
[root@node ~]# find /bin/ /sbin/ -type f -mmin -5
/bin/python2.7
/bin/gg

# 2.5 find 基于用户查找

# 查找属主为 jack 的文件
[root@jaxxwang ~]# find /home -user jack

# 查找属组为 admin 的文件
[root@jaxxwang ~]# find /home -group admin

# 查找属主为 jack，属组为 admin 的文件
[root@jaxxwang ~]# find /home -user jack -group admin

# 查找属主为 jack，并且属组为 admin 的文件
[root@jaxxwang ~]# find /home -user jack -a -group admin

# 查找属主为 jack，或者属组为 admin 的文件
[root@jaxxwang ~]# find /home -user jack -o -group admin

# 查找没有属主的文件
[root@jaxxwang ~]# find /home -nouser

# 查找没有属组的文件
[root@jaxxwang ~]# find /home -nogroup

# 查找没有属主或没有属组的文件
[root@jaxxwang ~]# find /home -nouser -o -nogroup

# 2.6 find 基于权限查找

-perm [/|-]MODE
  • MODE：精确权限匹配
  • -MODE：每一类对象都必须同时拥有指定的权限（并且的关系）
  • /MODE：任何一类（UGO）只要有一位匹配即可（或者的关系）
# 精确匹配权限
[root@web ~]# find /root -type f -perm 644 -ls

# -MODE：用户、组、其他都必须同时拥有该权限
[root@web ~]# find /root -type f -perm -644 -ls

# /MODE：用户或组或其他只要有一位匹配即可
[root@web ~]# find /root -type f -perm /644 -ls

# 精确查找特殊权限位（SUID/SGID/Sticky）
[root@web ~]# find /usr/bin/ /usr/sbin/ -type f -perm -4000 -ls
[root@web ~]# find /usr/bin/ /usr/sbin/ -type f -perm -2000 -ls
[root@web ~]# find /usr/bin/ /usr/sbin/ -type f -perm -1000 -ls

# 2.7 find 逻辑运算符

符号作用
-a与
-o或
-not | !非
#1. 查找非 root 用户的文件
[root@jaxxwang ~]# find . -not -user root
[root@jaxxwang ~]# find . ! -user root

#2. 查找属主为 hdfs，并且大小大于 1k 的文件
[root@jaxxwang ~]# find . -type f -a -user hdfs -a -size +1k

#3. 查找属主为 hdfs 或文件名为 xml 的文件
[root@jaxxwang ~]# find . -type f -a \( -user hdfs -o -name '*.xml' \)

注意：使用 -o（或）逻辑时，需要用 \( ... \) 将条件包裹，否则 find 的默认 -a（与）优先级会高于 -o，导致条件不符合预期。

# 3. find 动作处理

查找到一个文件后，需要对文件进行如何处理，find 的默认动作是 -print。

动作含义
-print打印查找到的内容（默认）
-ls以长格式显示的方式打印查找到的内容
-delete删除查找到的文件（仅能删除空目录）
-ok后面跟自定义 shell 命令（会提示是否操作）
-exec后面跟自定义 shell 命令（标准写法 -exec ... \;）

# 3.1 find 结合 exec

使用 -exec 实现文件拷贝和文件删除。

[root@jaxxwang ~]# find /etc -name "ifcfg*" -exec cp -rvf {} /tmp \;
[root@jaxxwang ~]# find /etc -name "ifcfg*" -exec rm -f {} \;

# 3.2 find 结合 xargs

  • xargs 将前者命令查找到的文件作为一个整体传递后者命令的输入，所以其操作的性能极高。
  • exec 是将文件一个一个地处理，所以处理性能极低。
# 测试性能对比
[root@jaxxwang ~]# touch file-{1..10000}

# 使用 -exec 逐个处理（性能低）
[root@jaxxwang ~]# find /etc -name "ifcfg*" -exec rm -f {} \;

# 使用 xargs 整体传递（性能高）
[root@jaxxwang ~]# find ./ -name "file*" | xargs rm -f

# 使用 xargs -I 指定替换字符
[root@jaxxwang ~]# find /usr/sbin/ -type f -perm -4000 | xargs -I {} cp -rv {} /tmp

# 3.3 find 结合 grep

当忘记重要配置文件存储路径时，可通过搜索关键字获取文件其路径。

[root@jaxxwang ~]# find /code -type f | xargs grep -R "MySQL_PASSWORD"
