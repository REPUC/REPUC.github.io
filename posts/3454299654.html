# Playbook 命令、入门实战与错误处理

本文讲解 ansible-playbook 的命令选项，并通过几个入门实战案例（创建用户、安装 nginx、安装/卸载 httpd、安装 MySQL）带你动手编写 Playbook，最后介绍 ignore_errors 错误处理机制。这些案例是编写更复杂剧本的基础。

# 一、ansible-playbook 命令

格式：

ansible-playbook <filename.yml> ... [options]

常用选项：

选项说明示例
--syntax-check语法检查（可缩写 --syntax，相当于 bash -n）ansible-playbook --syntax-check hello.yaml
-C, --check模拟执行（dry run），只检测可能的改变但不真正执行ansible-playbook -C hello.yaml
--list-hosts列出运行任务的主机ansible-playbook hello.yaml --list-hosts
--list-tags列出 tagansible-playbook hello.yaml --list-tags
--list-tasks列出 taskansible-playbook hello.yaml --list-tasks
--limit 主机列表针对特定主机执行ansible-playbook hello.yaml --limit 192.168.80.28
-i INVENTORY指定主机清单文件ansible-playbook hello.yaml -i /root/hosts
--start-at-task 名称从指定 task 开始执行（非从头）ansible-playbook hello.yml --start-at="start httpd"
-v -vv -vvv显示过程ansible-playbook -v hello.yml

示例：

[root@ansible ansible] cat hello.yml
---
- hosts: websrvs
  tasks:
    - name: hello
      command: echo "hello ansible"

[root@ansible ansible] ansible-playbook hello.yml
[root@ansible ansible] ansible-playbook -v hello.yml

建议：执行 Playbook 前先用 --syntax-check 检查语法，再用 -C 模拟执行确认预期，最后再真实执行。这是稳妥的三段式操作习惯。

# 二、入门实战案例

# 2.1 利用 Playbook 创建 MySQL 用户

# mysql_user.yml
---
- hosts: dbsrvs
  remote_user: root
  gather_facts: no

  tasks:
    - name: "创建组"
      group: name=mysql system=yes gid=306
    - name: "创建用户"
      user:
        name=mysql
        shell=/sbin/nologin
        system=yes
        group=mysql
        uid=306
        home=/data/mysql
        create_home=no
# 检查远程主机用户信息
ansible dbsrvs -m shell -a "id mysql"

# 验证 PlayBook（模拟执行）
ansible-playbook -C mysql_user.yml

# 执行脚本
ansible-playbook mysql_user.yml

# 2.2 利用 Playbook 安装 nginx

准备工作：在主控端准备配置文件和网页文件。

# 先卸载远程主机的 HTTPD
ansible websrvs -m yum -a 'name=httpd state=absent'

# 主控端安装 nginx 软件包（主要为拿到 nginx conf 文件）
yum install nginx -y
mkdir files

# 拷贝 nginx 配置文件并修改监听端口
cp /etc/nginx/nginx.conf files/
vim files/nginx.conf
#   server {
#       listen       8080;           # 修改该行
#       ...

# 编写 HTML 文件
vim files/index.html
<!DOCTYPE html>
<html>
<head>
    <meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
    <h1> Hello Ansible </h1>
</head>
<body>
</body>
</html>

编写 PlayBook：

# install_nginx.yml
---
- hosts: websrvs
  remote_user: root
  gather_facts: no

  tasks:
    - name: "Add Nginx Group"
      group: name=nginx state=present
    - name: "Add Nginx User"
      user: name=nginx state=present group=nginx
    - name: "Install Nginx"
      yum: name=nginx state=present
    - name: "Copy Nginx Config File"
      copy: src=files/nginx.conf dest=/etc/nginx/nginx.conf
    - name: "Copy Web Page File"
      copy: src=files/index.html dest=/usr/share/nginx/html/index.html
    - name: "Start Nginx Service"
      service: name=nginx state=started enabled=yes
# 验证 PlayBook
ansible-playbook -C install_nginx.yml

# 执行
ansible-playbook install_nginx.yml

# 验证端口启用情况
ansible websrvs -m shell -a 'netstat -nltp | grep 8080'

# 2.3 利用 Playbook 安装和卸载 httpd

安装 httpd 并修改配置：

# install_httpd.yml
---
- hosts: websrvs
  remote_user: root
  gather_facts: no

  tasks:
    - name: "Install httpd"
      yum: name=httpd
    - name: "Modify config listen port"
      lineinfile:
        path: /etc/httpd/conf/httpd.conf
        regexp: '^Listen'
        line: 'Listen 8080'
    - name: "Modify config data directory one"
      lineinfile:
        path: /etc/httpd/conf/httpd.conf
        regexp: '^DocumentRoot "/var/www/html"'
        line: 'DocumentRoot "/data/html"'
    - name: "Modify config data directory two"
      lineinfile:
        path: /etc/httpd/conf/httpd.conf
        regexp: '^<Directory "/var/www/html">'
        line: '<Directory "/data/html">'
    - name: "Mkdir website directory"
      file: path=/data/html state=directory
    - name: "copy Web html file"
      copy: src=files/index.html dest=/data/html/
    - name: "Start httpd service"
      service: name=httpd state=started enabled=yes
# 验证
ansible-playbook -C install_httpd.yml

# 仅针对特定主机执行
ansible-playbook install_httpd.yml --limit 192.168.80.28

卸载 httpd：

# remove_httpd.yml
---
- hosts: websrvs
  remote_user: root
  gather_facts: no

  tasks:
  - name: "remove httpd package"
    yum: name=httpd state=absent
  - name: "remove apache user"
    user: name=apache state=absent
  - name: "remove config file"
    file: name=/etc/httpd state=absent
  - name: "remove web html"
    file: name=/data/html/ state=absent
ansible-playbook -C remove_httpd.yml
ansible-playbook remove_httpd.yml

# 2.4 利用 Playbook 安装 MySQL 5.6

以安装 mysql-5.6.46-linux-glibc2.12 为例，演示用 tar 包安装 MySQL 的完整流程。

准备文件：

[root@ansible ~] ls -l /data/ansible/files/mysql-5.6.46-linux-glibc2.12-x86_64.tar.gz

# my.cnf 配置文件
[root@ansible ~] cat /data/ansible/files/my.cnf
[mysqld]
socket=/tmp/mysql.sock
user=mysql
symbolic-links=0
datadir=/data/mysql
innodb_file_per_table=1
log-bin
pid-file=/data/mysql/mysqld.pid

[client]
port=3306
socket=/tmp/mysql.sock

[mysqld_safe]
log-error=/var/log/mysqld.log

secure_mysql.sh（安全初始化脚本）：

#!/bin/bash
/usr/local/mysql/bin/mysql_secure_installation <<EOF
y
<密码>
<密码>
y
y
y
y
EOF

安装 PlayBook：

# install_mysql.yml
---
- hosts: dbsrvs
  remote_user: root
  gather_facts: no

  tasks:
    - name: "install packages"
      yum: name=libaio,perl-Data-Dumper,perl-Getopt-Long
    - name: "create mysql group"
      group: name=mysql gid=306
    - name: "create mysql user"
      user: name=mysql uid=306 group=mysql shell=/sbin/nologin system=yes create_home=no home=/data/mysql
    - name: "copy tar to remote host and file mode"
      unarchive: src=/data/ansible/files/mysql-5.6.46-linux-glibc2.12-x86_64.tar.gz dest=/usr/local/ owner=root group=root
    - name: "create linkfile /usr/local/mysql"
      file: src=/usr/local/mysql-5.6.46-linux-glibc2.12-x86_64 dest=/usr/local/mysql state=link
    - name: "data dir"
      shell: chdir=/usr/local/mysql/ ./scripts/mysql_install_db --datadir=/data/mysql --user=mysql
      tags: data
    - name: "config my.cnf"
      copy: src=/data/ansible/files/my.cnf dest=/etc/my.cnf
    - name: "service script"
      shell: /bin/cp /usr/local/mysql/support-files/mysql.server /etc/init.d/mysqld
    - name: "enable service"
      shell: /etc/init.d/mysqld start;chkconfig --add mysqld;chkconfig mysqld on
      tags: service
    - name: "PATH variable"
      copy: content='PATH=/usr/local/mysql/bin:$PATH' dest=/etc/profile.d/mysql.sh
    - name: "secure script"
      script: /data/ansible/files/secure_mysql.sh
      tags: script

该案例综合运用了 yum、group、user、unarchive、file、shell、copy、script 等模块，并演示了 tags 的使用（data/service/script 三类任务打标签，可单独执行某一阶段）。

# 三、ignore_errors：忽略错误

默认行为：如果一个 Task 出错，默认不会继续执行后续的其它 Task。

ignore_errors: yes 可忽略此 Task 的错误，继续向下执行 Playbook 其它 Task。

# test_ignore.yml
---
- hosts: websrvs

  tasks:
    - name: error test
      command: /bin/false    # 返回失败结果的命令
      ignore_errors: yes     # 忽略错误，继续执行
    - name: continue
      command: wall continue
[root@ansible ansible] ansible-playbook test_ignore.yml

ignore_errors 适用于"某一步可能失败但不应阻断整体流程"的场景，例如安装可选组件、清理可能不存在的文件等。但要谨慎使用，避免掩盖真实错误。

# 小结

本文介绍了 ansible-playbook 的常用选项（语法检查、模拟执行、列主机/任务/标签、limit、start-at-task 等），并通过创建用户、安装 nginx、安装/卸载 httpd、安装 MySQL 四个实战案例演示了 Playbook 的编写套路，最后讲解了 ignore_errors 错误处理。

Playbook 的通用结构是：hosts → remote_user → gather_facts → tasks（按模块组织）。下一篇将深入 Playbook 的进阶特性：Handlers 与 notify、Tags 标签，以及变量的多种来源与优先级。
